# Calculator

A simple browser-based calculator built as a part of The Odin Project's Calculator assignment.

---

## Features

- A display
- Numbers 0 - 9
- Math operators (=,+,-,*,/)
- Decimal Point 
- Backspace and Clear buttons

---

## Technologies

- HTML
- CSS 
- JavaScript
